# vscode-just-func

Syntax highlighting for the [`just-func`](https://github.com/justland) language.

## Features

Registers the `just-func` language for `.jf` files, with a TextMate grammar
(`syntaxes/just-func.tmLanguage.json`) and bracket, comment, and auto-closing-pair rules
(`language-configuration.json`).

## Requirements

VS Code 1.134.0 or later.

## Status

Unpublished. Run it from source with the `Run Extension` launch configuration in this folder.
