# vscode-just-web

VS Code support for [`just-web`](https://github.com/justland) applications.

## Features

Contributes the `vscode-just-web.helloWorld` command. The extension is still a scaffold — the
`just-web` specific features are not implemented yet.

## Requirements

VS Code 1.134.0 or later.

## Status

Unpublished. Run it from source with the `Run Extension` launch configuration in this folder, and
see the [contributing guide](../../CONTRIBUTING.md) for the test command.
